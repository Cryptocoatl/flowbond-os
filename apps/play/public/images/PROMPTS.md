# Kai World — image generation prompts (Grok / GPT / any model)

**How to use:** paste the STYLE BIBLE first, then one asset prompt. Generate,
then save the file with the EXACT name shown into the matching folder. The app
loads it automatically (each slot has a fallback so nothing breaks meanwhile).
Save as `.webp` if you can; if not, drop the PNG/JPG in `~/Downloads` and tell
ClaudIA — she'll convert + place them.

Consistency tip: generate all 8 guardians in ONE session ("same art style, same
lighting as the previous image") so the set looks like one family.

---
